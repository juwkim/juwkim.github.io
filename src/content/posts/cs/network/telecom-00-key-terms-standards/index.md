## 1. 주요 프로토콜 및 네트워크 기술

### 1.1. 애플리케이션 및 전송 계층 프로토콜

- **TCP/IP:** 인터넷 통신의 핵심 프로토콜 규약이다.
    - **TCP (Transmission Control Protocol):** 전송 계층의 신뢰성 있는 **연결 지향형** 프로토콜로, **3-Way Handshake**를 통해 연결을 설정하고 흐름 제어, 혼잡 제어, 오류 제어를 수행하여 데이터의 정확한 전송을 보장한다.
    - **UDP (User Datagram Protocol):** 전송 계층의 **비연결 지향형** 프로토콜로, 신뢰성 제어 오버헤드가 없어 데이터 전송 속도가 빠르며 실시간 스트리밍 및 소용량 통신(DNS, DHCP, SNMP 등)에 사용된다.
- **HTTP (Hypertext Transfer Protocol):** 웹 서버와 클라이언트 간에 텍스트, 이미지 등 멀티미디어 자원을 주고받기 위해 사용하는 **Stateless** 방식의 애플리케이션 계층 프로토콜이다.
- **HTTPS (HTTP Secure):** HTTP에 **SSL/TLS** 보안 세션 규격을 추가하여 기밀성 암호화, 데이터 무결성 검증, 서버 인증서 확인 기능을 제공하는 안전한 전송 프로토콜이다.
- **DNS (Domain Name System):** 인간이 식별하기 쉬운 **문자 형태의 도메인 이름을 컴퓨터가 처리할 수 있는 IP 주소로 변환**(정방향 조회)하거나 그 반대의 동작(역방향 조회)을 수행하는 분산 데이터베이스 시스템이다.
- **DHCP (Dynamic Host Configuration Protocol):** 네트워크 내의 호스트에게 **IP 주소, 서브넷 마스크, 기본 게이트웨이, DNS 서버 주소 등의 네트워크 설정 정보를 동적으로 자동 할당**하고 회수하는 프로토콜이다.
- **SMTP (Simple Mail Transfer Protocol):** 클라이언트가 메일 서버로 메일을 보낼 때, 또는 메일 서버 간에 전자우편(E-mail)을 전송(송신)할 때 사용하는 프로토콜이다.
- **POP3 (Post Office Protocol version 3):** 메일 서버의 수신함에 보관 중인 전자우편을 **클라이언트(로컬 PC)로 다운로드하여 읽을 때** 사용하는 프로토콜이다. 서버에서 메일이 삭제되는 것이 기본 동작이다.
- **IMAP (Internet Message Access Protocol):** POP3와 유사한 이메일 수신 프로토콜이나, **메일을 로컬로 다운로드하지 않고 서버에 그대로 둔 채** 여러 기기에서 동기화하여 관리할 수 있도록 지원하는 상위 프로토콜이다.
- **FTP (File Transfer Protocol):** TCP 기반으로 대용량 파일을 네트워크를 통해 대화형으로 전송하기 위한 프로토콜이다. 제어 연결과 데이터 연결을 완전히 분리하여 처리한다.
- **SSH (Secure Shell):** 패킷이 평문으로 전송되어 보안에 취약한 Telnet, rlogin 등을 대체하기 위해, **강력한 암호화 및 인증 기능을 제공하여 원격 서버 제어 및 파일 전송을 안전하게 수행**하는 프로토콜이다.
- **Telnet:** 암호화 기능을 지원하지 않아 네트워크 스니핑에 취약한 전통적인 가상 터미널 원격 접속 프로토콜이다.

### 1.2. 네트워크 및 데이터 링크 계층 기술

- **ARP (Address Resolution Protocol):** 동일 서브넷 내에서 논리적인 **IP 주소를 기반으로** 해당 장비의 물리적인 **MAC 주소(하드웨어 주소)를 찾아내기 위해** 사용하는 3계층 프로토콜이다. 구현 시 브로드캐스트 방식을 활용한다.
- **RARP (Reverse Address Resolution Protocol):** IP 주소가 없는 호스트가 자신의 **물리적인 MAC 주소를 매개로 서버로부터 IP 주소를 할당받기 위해** 사용하는 역주소 변환 프로토콜이다.
- **ICMP (Internet Control Message Protocol):** 네트워크 계층 프로토콜인 IP의 신뢰성 없는 특성을 보완하기 위해, **IP 패킷 전송 중 발생하는 오류 상황을 송신측에 보고하고 경로 및 접속 상태를 진단**하는 프로토콜이다. ping, traceroute 명령의 기반이 된다.
- **IGMP (Internet Group Management Protocol):** 멀티캐스트 라우터와 호스트 간에 **멀티캐스팅 그룹 멤버십을 등록, 관리, 통지**하기 위해 사용하는 네트워크 계층 프로토콜이다.
- **NAT (Network Address Translation):** IPv4 주소 고갈 문제를 해결하고 내부 네트워크 구성을 은닉하기 위해, **내부 사설 IP 주소를 외부 공인 IP 주소로 변환**하는 기술이다. 1대다 변환 기술은 별도로 **NAPT / PAT**라고 칭한다.
- **VPN (Virtual Private Network):** 공용 인터넷망을 암호화 기술과 터널링 프로토콜을 활용하여 마치 **기업 전용 회선처럼 안전하고 독립적으로 사용할 수 있게 하는 가상 사설망 기술**이다.
    - **터널 모드 (Tunnel Mode):** 원래의 IP 패킷 전체(기본 헤더 포함)를 암호화한 뒤 새로운 IP 헤더와 IPsec 헤더를 추가하는 모드로, 게이트웨이 대 게이트웨이(Site-to-Site) 구간 보안에 주로 쓰인다.
    - **트랜스포트 모드 (Transport Mode):** IP 패킷의 페이로드(데이터 영역)만 암호화하고 원래의 IP 헤더는 그대로 유지하는 모드로, 종단 호스트 간 통신 보안에 쓰인다.
- **CSMA/CD:** 유선 LAN(IEEE 802.3 이더넷)의 매체 접근 제어 방식으로, 회선의 반송파를 감지하여 비어 있을 때 전송하되, **동시 전송으로 인한 충돌을 감지하면 잼(Jam) 신호를 송신하고 랜덤 시간 후 재전송**한다.
- **CSMA/CA:** 무선 LAN(IEEE 802.11 와이파이)의 매체 접근 제어 방식으로, 무선 매체의 특성상 충돌 감지가 어려우므로 **전송 전에 IFS 대기 시간과 임의의 백오프(Back-off) 시간을 거쳐 충돌을 사전에 회피**한다. 추가로 RTS/CTS 프레임을 교환하여 숨겨진 터미널 문제를 해결한다.

### 1.3. 다중화 및 다중 접속 기술

- **OFDMA (Orthogonal Frequency Division Multiple Access):** 직교 주파수 분할 다중 접속 방식으로, 하나의 채널을 시간(Time Slot)과 주파수(Subcarrier) 축에서 세부 조각(Resource Unit)으로 쪼개어 **다수의 사용자에게 동시 분배함으로써 주파수 이용 효율과 처리량을 극대화**한 기술이다. Wi-Fi 6, 5G 가입자망 핵심 기술로 꼽힌다.
- **TDM (Time Division Multiplexing):** 하나의 물리적 전송로 채널 대역폭을 **서로 다른 시간 슬롯(Time Slot)으로 분할**하여 다수의 독립된 신호를 결합 전송하는 시분할 다중화 방식이다.
- **FDM (Frequency Division Multiplexing):** 하나의 물리적 전송로 대역폭을 **서로 다른 주파수 대역 영역으로 분할**하고 채널 간 간섭을 막기 위해 보호 대역(Guard Band)을 두어 다중화하는 방식이다.
- **CDMA (Code Division Multiple Access):** 동일한 주파수 대역과 시간 공간을 전체 공유하되, **사용자마다 서로 직교하는 고유의 확산 코드(Pseudo-Noise Code)를 부여**하여 채널을 논리적으로 구분하는 코드 분할 다중 접속 방식이다.
- **WDM (Wavelength Division Multiplexing):** 단일 광섬유 규격 내에서 주파수가 다른(즉, **파장이 다른**) 여러 개의 광신호를 동시에 결합하여 전송하는 파장 분할 다중화 방식이다. 고밀도 대용량 전송을 위한 방식을 **DWDM**이라 한다.
- **PON (Passive Optical Network):** 광가입자망(FTTH) 구간에 전력 공급이 필요 없는 **스플리터(Splitter) 같은 수동형 광부품을 배치**하여 하나의 OLT(국선 장비) 포트 라인을 다수의 가입자(ONU/ONT)가 공유하도록 하는 경제적인 광 네트워크 기술이다.

### 1.4. 가입자망 및 근거리 무선 인프라

- **xDSL (Digital Subscriber Line):** 기존 유선 전화선(동선)의 고주파 대역을 활용하여 초고속 데이터 통신을 가입자망에 구현하는 기술의 총칭이다. 비대칭형인 ADSL, 고속형인 VDSL 등이 포함된다.
- **Bluetooth:** 2.4GHz ISM 대역을 사용하는 근거리 무선 개인 영역 네트워크(WPAN) 표준 기술이다. 마스터-슬레이브 구조의 피코넷(Piconet)을 형성하며, 간섭 회피를 위해 주파수 도약(FHSS) 기술을 쓴다.
- **Zigbee:** IEEE 802.15.4 표준에 기반하여 저속, 저비용, **저전력 배터리 구동을 최우선 목표**로 설계된 홈 네트워킹 및 스마트 팩토리 센서 노드용 무선 메시 네트워크 기술이다.
- **UWB (Ultra-Wideband):** 매우 넓은 주파수 대역폭에 걸쳐 **매우 낮은 전력 밀도의 펄스 신호를 방사하여 수 센티미터 수준의 초정밀 위치 측정**과 대용량 단거리 데이터 전송을 가능하게 하는 초광대역 통신 기술이다.

## 2. 정보통신 표준 및 핵심 기술

### 2.1. IEEE 802 표준 규격

- **IEEE 802.1:** 상위 계층 인터페이스 표준, 전체 LAN/MAN 아키텍처, 네트워크 브리지 연동 및 계층 보안(802.1X 인증) 등을 정의한다.
- **IEEE 802.2:** 데이터 링크 계층의 상위 서브 계층인 **LLC (Logical Link Control, 논리 링크 제어)** 규격이다.
- **IEEE 802.3:** **이더넷 (Ethernet)** 유선 LAN 표준 규격으로 CSMA/CD 매체 제어 방식 및 이더넷 프레임 구조를 정의한다.
- **IEEE 802.4:** 토큰 버스 (Token Bus) 매체 제어 방식 규격이다. (현재는 사용되지 않는 레거시 기술)
- **IEEE 802.5:** 토큰 링 (Token Ring) 매체 제어 방식 규격이다. (현재는 사용되지 않는 레거시 기술)
- **IEEE 802.11:** **와이파이 (Wi-Fi)** 무선 LAN 표준 규격군이다.
    - **802.11a:** 5GHz 대역 사용, OFDM 변조 적용으로 최대 54Mbps 속도 제공.
    - **802.11b:** 2.4GHz 대역 사용, DSSS 변조 적용으로 최대 11Mbps 속도 제공.
    - **802.11g:** 2.4GHz 대역 사용, OFDM 변조를 도입하여 최대 54Mbps 속도 제공.
    - **802.11n:** 2.4/5GHz 겸용 대역 사용, **MIMO (다중입출력)** 안테나 기술과 채널 결합(Bonding)을 도입하여 최대 600Mbps 지원.
    - **802.11ac:** 5GHz 대역 전용, 다운링크 MU-MIMO 기술 도입으로 기가비트(Gbps) 속도 구현.
    - **802.11ax (Wi-Fi 6):** 2.4/5GHz 대역 사용, **OFDMA 및 1024-QAM** 변조 적용으로 고밀도 다중 접속 환경 내 밀집 병목을 해소한 고효율 표준.
    - **802.11be (Wi-Fi 7):** 최대 320MHz 채널 대역폭 및 **4096-QAM**, **MLO (Multi-Link Operation)** 기술을 도입하여 초고속·초저지연을 달성한 차세대 무선 규격.
- **IEEE 802.15:** WPAN(무선 개인 영역 네트워크) 표준으로 블루투스, 지그비, 고속 무선 전송 기술의 물리 및 매체 제어 계층을 다룬다.

### 2.2. 미디어 및 방송 코덱 표준

- **MPEG 표준 시리즈 (ISO/IEC 국제 표준)**
    - **MPEG-1:** CD-ROM 등 저장매체를 타겟으로 설계된 초기 동영상 압축 규격으로 비디오 CD 및 MP3의 모태가 된다.
    - **MPEG-2:** **HDTV 디지털 방송 전송 표준** 및 DVD 매체에 전방위적으로 채택된 고화질 인터레이스 영상 압축 표준이다.
    - **MPEG-4:** 멀티미디어 개체(Object) 기반 부호화를 구현하여 낮은 대역폭의 대화형 통신, 인터넷 스트리밍 및 모바일 환경에 최적화된 고효율 표준이다.
    - **MPEG-7:** 멀티미디어 데이터의 **내용 기반 표현(Content Description)** 및 구조화된 메타데이터 검색, 색인 기능을 정의하는 표준이다. (압축 코덱이 아님)
    - **MPEG-21:** 멀티미디어 콘텐츠의 생성, 거래, 유통, 소비 및 **저작권 보호(DRM/IPMP)** 등 전 과정을 유기적으로 통합 관리하기 위한 멀티미디어 프레임워크 규격이다.
- **H.26x 표준 시리즈 (ITU-T 비디오 코딩 표준)**
    - **H.264 / MPEG-4 AVC:** 우수한 압축률과 범용성으로 전 세계 대다수의 스트리밍, 디지털 방송, 영상 플랫폼 환경에서 표준 코덱으로 사용된다.
    - **H.265 / MPEG-H HEVC (High Efficiency Video Coding):** H.264 대비 **데이터 압축 효율을 2배 가까이 향상**시키고 화질 열화를 제어하여 4K/8K 초고화질(UHD) 방송 인프라에 적합하도록 정립된 규격이다.
- **ATSC (Advanced Television Systems Committee):** 북미식 디지털 지상파 방송 표준 체계이다.
    - **ATSC 1.0:** MPEG-2 비디오 코덱과 8-VSB 전송 방식을 기반으로 하는 전통적 HD 방송 표준이다.
    - **ATSC 3.0 (최신):** **HEVC(H.265) 비디오 코덱과 주파수 효율이 높은 OFDM 전송 방식**을 채택하고 통신 프로토콜 체계를 **IP 기반**으로 완전히 전환하여, 4K UHD 방송, 재난 방송 인터랙티브 서비스, 모바일 방송 동시 전송을 지원하는 차세대 방송 표준이다.

### 2.3. 차세대 암호화 인프라 및 광소자

- **양자 보안 기술 (Quantum Security)**
    - **QKD (Quantum Key Distribution, 양자 키 분배):** 양자 역학의 물리적 특성(단일 광자의 상태)을 기반으로 송수신자 사이에 비밀키를 안전하게 분배하는 기술로, 제3자의 **도청 시도가 있을 경우 양자 상태가 무조건 교란되어 변형되므로 절대적인 도청 탐지**가 가능하다.
    - **PQC (Post-Quantum Cryptography, 양자 내성 암호):** 양자 컴퓨터의 쇼어(Shor) 알고리즘 기반 고속 소인수분해 연산 공격에도 안전할 수 있도록, 기존 비대칭 암호를 보완하여 격자(Lattice), 다변수(Multivariate) 등 **매우 복잡한 수학적 난제를 기반으로 설계한 소프트웨어적 차세대 암호 알고리즘**이다.
    - **QRNG (Quantum Random Number Generator, 양자 난수 생성기):** 소프트웨어의 결정론적 알고리즘(의사 난수)을 탈피하고, 자연계 양자의 본질적 무작위성을 계측하여 **패턴 분석 및 예측이 원천적으로 불가능한 고순도 순수 난수를 생성**하는 하드웨어 소자이다.
    - **양자의 3대 물리적 특성:** 하나의 양자가 여러 상태로 동시에 존재할 수 있는 **중첩성**, 측정하기 전까지 상태를 확정할 수 없는 **불확실성**, 한 번 변형된 양자 상태는 이전으로 되돌리거나 완벽히 똑같이 복제할 수 없는 비가역성(복제 불가능성)이 있다.
- **보안 암호화 전송 프로토콜**
    - **IPsec:** 네트워크 계층(3계층)에서 IP 패킷 수준의 무결성 검증과 기밀성 암호화를 직접 제공하는 표준 보안 아키텍처이다. (AH, ESP 헤더 프로토콜 사용)
    - **TLS:** 전송 계층(4계층)에서 작동하며 보안 결함이 발견된 기존 SSL을 대체하여, 서버-클라이언트 종단 간 데이터 암호화, 인증, 가변 메시지 무결성을 제공하는 암호화 프로토콜이다.
- **광통신 발광 소자**
    - **LD (Laser Diode, 레이저 다이오드):** 위상이 균일하고 단색성, 직진성이 우수한 결맞음 광(Coherent Light)을 방출하는 소자이다. 응답 속도가 빠르고 주파수 스펙트럼 폭이 좁아 **단일모드 광섬유(SMF)를 이용한 대용량, 장거리 전송 인프라**에 사용된다.
    - **LED (Light Emitting Diode, 발광 다이오드):** 방출되는 광의 스펙트럼 폭이 넓고 퍼지는 성질의 비결맞음 광(Incoherent Light)을 출력하는 소자이다. 가격이 저렴하고 수명이 길지만 변조 대역폭이 좁아 **다중모드 광섬유(MMF)를 이용한 단거리, 소용량 통신 인프라**에 제한적으로 쓰인다.

## 3. 정보보안 관련 용어

- **보안의 3대 핵심 요소 (CIA Triad)**
    1. **무결성 (Integrity):** 시스템 내의 정보가 인가되지 않은 외부 변조, 가공, 고의적 오염 없이 **정확성과 완전성을 유지**하도록 보장하는 특성이다. 해시 함수나 디지털 서명으로 검증한다.
    2. **기밀성 (Confidentiality):** 오직 권한을 부여받은 인가된 사용자나 시스템만이 정보 자산에 접근할 수 있도록 차단하고 제어하는 특성이다. 대칭 및 비대칭 암호화, 접근 제어 정책으로 구현한다.
    3. **가용성 (Availability):** 정당한 권한을 가진 사용자가 **필요한 시점에 지연이나 방해 없이 정보 시스템 및 자원을 즉시 정상 사용**할 수 있도록 보장하는 특성이다. 서버 백업, 장비 이중화, 인프라 고가용성 설계로 확보한다.
- **DDoS (Distributed Denial of Service, 분산 서비스 거부 공격):** 공격자가 원격지의 수많은 분산 에이전트(좀비 PC, 봇넷)를 감염 및 통제하여, **표적 시스템에 정상 범위 이상의 대량의 트래픽을 한꺼번에 집중 발생시킴으로써 네트워크 대역폭과 컴퓨팅 자원을 고갈시켜 정당한 서비스를 마비**시키는 대규모 공격이다.
- **경계 보안 인프라 장비**
    - **Firewall (방화벽):** 신뢰 수준이 다른 네트워크 경계(내부망과 외부 인터넷망 사이)에 위치하여, **사전에 정의된 패킷 필터링 보안 규칙(IP 주소, 포트 번호 기반)에 의거해 외부 비인가 트래픽을 일차적으로 차단**하는 시스템이다.
    - **IPS (Intrusion Prevention System, 침입 방지 시스템):** 방화벽 하부 단계에 위치하여, 유입되는 실시간 네트워크 트래픽 내부의 **패킷 페이로드 내용까지 정밀 심층 분석(DPI)하여 악성코드 유입 및 기지의 취약점 공격 시도를 능동적으로 직접 차단**하는 침입 방지 시스템이다.

## 4. 정보통신망 및 시스템 구성 기술

- **정보통신망의 3대 제어 기능:** 망 내부에서 소통을 통제하는 핵심 기능군이다.
    - **신호 기능:** 호(Call)의 설정, 유지, 해제를 위해 교환기 간 제어 정보를 교환하는 기능이다.
    - **전달 기능:** 사용자 정보(데이터, 음성 등)를 물리적 전송로를 통해 목적지까지 송수신하는 기능이다.
    - **제어 기능:** 망 전체의 효율적 운영을 위해 경로 배정(Routing), 흐름 제어, 폭주 제어를 관리하는 기능이다.
- **망 신뢰성 향상 및 생존성 확보 방안:**
    - 인프라 단일 장애점(SPOF)을 제거하기 위한 핵심 장비 및 선로의 **이중화(Redundancy)** 구성이 필요하다.
    - 모든 노드가 그물망처럼 유기적으로 얽혀 하나의 경로가 끊겨도 즉시 우회로를 여는 **풀메시(Full-Mesh)** 토폴로지 레이아웃을 구축한다.
    - 전사적 관제를 위한 **NMS(Network Management System)** 모니터링을 도입하고 장애 인지 시 가동 중단 시간(Down-time)을 최소화하는 복구 메커니즘을 수립한다.
- **물리적 데이터 통신 방식 분류**
    1. **단방향 (Simplex):** 송신측과 수신측이 물리적으로 완전 고정되어 한쪽 방향으로만 정보 전달이 가능한 통신 방식이다. 지상파 방송 수신이나 무선 호출기 등이 이에 해당한다.
    2. **반이중 (Half-duplex):** 양방향 데이터 전송은 모두 가능하나, 물리 매체를 공유하므로 **동시에 송수신할 수 없고 양측이 번갈아 가며 한 방향씩 교대로 전송**해야 하는 통신 방식이다. 무전기나 CSMA/CD 기반 이더넷 허브 환경이 대표적이다.
    3. **전이중 (Full-duplex):** 송신 채널과 수신 채널이 물리적 혹은 논리적(FDD, TDD 기술)으로 완전히 분리되어 있어, **송신과 수신을 지연 없이 동시에 양방향으로 수행**할 수 있는 통신 방식이다. 일반 전화기나 스위칭 유선 LAN이 이에 해당한다.
- **반송파 (Carrier Signal):** 음성이나 디지털 데이터 등 주파수 대역이 매우 낮은 기저대역 정보 신호를, 장거리 무선 선로 상에 실어 손실 없이 멀리 전송할 수 있도록 주파수 레벨을 고주파 대역으로 높여 변조할 때 기준이 되는 고주파 신호이다.
- **이동통신 코어망 가입자 데이터베이스**
    - **HLR (Home Location Register, 홈 위치 등록기):** 이동통신망 가입자의 영구적인 마스터 프로필 정보, 청구서 권한, 부가 서비스 승인 내역 및 **현재 가입자가 위치하고 있는 대략적인 교환국(MSC) 영역의 주소를 상시 추적·보존**하는 중앙 마스터 데이터베이스 서버이다.
    - **VLR (Visitor Location Register, 방문자 위치 등록기):** 타 지역에서 현재 자신이 관할하는 기지국 제어 영역 내부로 일시 진입한 **방문 가입자의 프로필 정보를 해당 가입자의 본가 HLR로부터 일시적으로 복사해 와 저장하고, 가입자의 상세 셀 위치를 밀착 추적**하는 지역 임시 데이터베이스 서버이다.
- **MDF (Main Distribution Frame, 주배선반):** 통신국사나 대형 건물 지하 통신실에 설치되어, 외부 국선 통신 케이블 배선들과 건물 내부의 각종 구내 교환 장비 및 세부 단말 선로들이 **한곳에 조밀하게 모여 상호 교차 연결 및 분기 제어**가 이루어지는 주배선 프레임판이다.

## 5. 유닉스/리눅스 CLI 명령어

### 5.1. 파일 및 디렉토리 제어

- **ls:** 지정된 디렉토리 내부의 파일 구조 및 하위 디렉토리 파일 명세를 리스트 형태로 출력한다.
- **cd:** 현재 셸 환경이 가리키는 작업 디렉토리의 위치(경로)를 변경한다.
- **pwd:** 현재 작업 지점이 위치한 디렉토리의 루트 기준 전체 절대 경로를 화면에 리턴한다.
- **mkdir:** 지정된 파일 경로 위치에 새로운 빈 디렉토리를 생성한다.
- **rmdir:** 내부에 파일이 들어있지 않은 완전히 비어 있는 디렉토리만을 선택적으로 삭제한다.
- **cp:** 소스 파일이나 디렉토리 원본을 지정한 타겟 경로 위치로 물리적 복사본을 생성한다.
- **mv:** 파일이나 디렉토리의 물리적 위치를 이동시키거나, 파일 자체의 명칭을 변경(Rename)할 때 쓴다.
- **rm:** 지정한 파일 또는 하위 폴더 전체를 파일 시스템에서 영구 삭제한다. `-rf` 옵션과 연계하여 사용할 수 있다.
- **find:** 하부 디렉토리 트리 전체 구조를 실시간 스캔하여 검색 조건(이름, 소유자, 크기 등)에 부합하는 파일들을 추적한다.
- **touch:** 용량이 0바이트인 빈 파일을 새롭게 즉시 생성하거나, 이미 존재하는 파일의 최종 수정 시간(타임스탬프) 정보만을 현재 시간으로 갱신한다.
- **cat:** 인자로 지정된 텍스트 파일의 기록 내용 전체를 터미널 화면에 개행 단위로 연속 출력한다.
- **more / less:** 긴 텍스트 파일의 내용을 화면 가독성에 맞게 단위 분할하여 터미널 화면에 페이지 형식으로 끊어서 출력한다. less가 스크롤링 기능 등 성능 면에서 더 우수하다.
- **zip / unzip:** 다수의 데이터를 하나의 ZIP 아카이브 포맷으로 압축 통합하거나, 반대로 원본으로 압축 해제한다.
- **tar:** 파일 시스템 내의 여러 개별 파일을 압축 없이 하나의 묶음 파일(Archive)로 묶어 결합하거나 결합을 푸는 도구이다.

### 5.2. 권한 및 사용자 계정 관리

- **chmod:** 파일 또는 디렉토리에 할당된 읽기(r=4), 쓰기(w=2), 실행(x=1)에 대한 소유자/그룹/기타 사용자 세부 접근 권한(Permission)을 변경하는 명령어이다. (사용 예시: `chmod 755 script.sh`)
- **chown:** 파일 및 디렉토리에 설정된 고유의 **소유자(Owner) 계정 권한 및 그룹**을 다른 사용자로 변경한다.
- **chgrp:** 파일의 사용자 소유 그룹 권한만을 특정 그룹으로 한정하여 변경한다.
- **who / whoami:** who는 현재 해당 서버 운영체제에 원격 등으로 세션 접속해 있는 전체 사용자 로그인 명세를 출력하고, whoami는 현재 터미널 셸 명령을 직접 타이핑하여 실행 중인 자기 자신의 현재 로그인 계정 ID만을 조회한다.

### 5.3. 네트워크 장애 진단 및 시스템 모니터링

- **ping:** **ICMP Echo Request** 패킷을 타겟 목적지 IP로 송신한 뒤, 이에 대응해 반환되는 Echo Reply 패킷을 측정하여 종단 시스템 간의 물리적 네트워크 연결성(Reachability) 및 왕복 지연 시간(RTT)을 진단하는 도구이다.
- **ifconfig / ipconfig:** 호스트에 장착된 네트워크 인터페이스 카드(NIC)의 IP 주소 설정 상태, 서브넷 마스크, MAC 주소 정보 등을 확인하고 제어하는 명령이다. 리눅스나 유닉스는 ifconfig, 윈도우는 ipconfig 명령어를 사용한다.
- **iwconfig:** 무선 네트워크 인터페이스 카드 전용 명령어로 무선 LAN의 SSID, 연결 주파수 대역, 무선 통신 감도 및 채널 품질 상태를 표시한다.
- **netstat:** 로컬 시스템에서 활성화되어 작동 중인 **TCP/UDP 소켓 연결 상태, 열려 있는 포트(Listening), 라우팅 테이블 정보, 프로토콜 계층별 입출력 통계**를 일목요연하게 모니터링한다.
- **nslookup:** 호스트가 지정한 DNS 네임 서버에 직접 도메인 관련 패킷 질의를 던져, 특정 도메인 주소에 연계된 공인 IP 주소 정보를 조회하여 찾아오는 진단 도구이다.
- **traceroute / tracert:** 목적지 IP 주소까지 데이터 패킷이 유입되는 이동 경로 상의 **모든 라우팅 게이트웨이 구간을 추적하고, 각 라우터 구간별 패킷 지연 및 유실 여부를 검증**한다. 리눅스는 traceroute, 윈도우는 tracert 명령어를 사용한다.
- **hostname:** 현재 사용 중인 서버 시스템 컴퓨터에 부여된 가상 호스트 명칭을 확인하거나 변경한다.
- **ps:** 현재 가동 중인 리눅스 메모리 상에 상주해 프로세서 자원을 점유하고 있는 **활성화된 프로세스들의 동작 상태 및 PID(프로세스 식별 번호)** 정보를 조회한다.
- **free:** 물리적 주 메모리(RAM)의 전체 크기, 현재 실제 사용량, 사용 가능한 잔여 여유 공간 및 스왑(Swap) 가상 메모리 공간 배정 상태를 단위별 출력한다.
- **vmstat:** 커널의 가상 메모리 점유 현황, 대기 프로세스 상태, 디스크 I/O 처리 상태, CPU 인터럽트 및 콘텍스트 스위칭 활동 통계를 실시간 수치 데이터로 통합 모니터링한다.
- **grep:** 인자로 지정된 대용량 텍스트 파일이나 유입되는 파이프 스트림 데이터 정보군 중에서, 개발자가 사전에 입력한 특정 문자열 정규표현식 패턴과 완벽히 매칭되는 행(Line)만을 필터링하여 화면에 발췌 출력한다.
- **man:** 리눅스 내장 핵심 명령어, 시스템 구성 설정 파일, 커널 함수에 대한 상세 사양과 옵션 정보가 수록된 사용자 매뉴얼 도움말 페이지를 터미널 상에 보여준다.
- **VI 텍스트 편집기 환경 제어 필수 단축키**
    - **wq:** 텍스트 변경 내역을 파일 시스템에 최종 저장(write)하고 편집기를 정상 종료(quit)한다.
    - **q!:** 작업한 편집 내용을 파일에 기록하지 않고 무시한 채 편집기를 강제 종료한다.
    - **dd:** 현재 텍스트 커서 라인이 위치하고 있는 행(Line) 전체를 즉시 잘라내어 삭제한다.
    - **u:** 직전에 수행한 파일 편집 명령 작업을 취소하고 이전 상태로 되돌린다. (Undo 기능)

## 6. Well-Known 포트 번호

- **Port 20 / 21:** FTP (File Transfer Protocol)
    - **20번 포트:** 실제 대용량 파일 데이터의 스트림 송수신을 처리하는 **데이터 연결(Data) 포트**이다.
    - **21번 포트:** 사용자 인증, 디렉토리 변경 명령어 등 제어 신호를 주고받는 **제어 연결(Control) 포트**이다.
- **Port 22:** SSH (Secure Shell) 보안 원격 셸 제어
- **Port 23:** Telnet 평문 원격 가상 터미널
- **Port 25:** SMTP (Simple Mail Transfer Protocol) 이메일 송신 및 서버 간 전달
- **Port 53:** DNS (Domain Name System) 주소 해석 질의. 기본적으로 대기 시간 최소화를 위해 UDP를 쓰며, 응답 데이터가 512바이트를 초과하거나 존 트랜스퍼 수행 시에는 신뢰성을 위해 TCP를 병행 사용한다.
- **Port 67 / 68:** DHCP (Dynamic Host Configuration Protocol)
    - **67번 포트:** DHCP 서버(Server)가 클라이언트의 요청 메시지를 수신 대기하는 포트이다.
    - **68번 포트:** DHCP 클라이언트(Client)가 서버의 응답 패킷을 수신 대기하는 포트이다.
- **Port 69:** TFTP (Trivial FTP) 인증 과정 없이 UDP 기반으로 단순하게 파일을 전송하는 간이 프로토콜 포트이다.
- **Port 80:** HTTP (Hypertext Transfer Protocol) 일반 평문 웹 서비스 포트이다.
- **Port 110:** POP3 (Post Office Protocol v3) 로컬 이메일 수신 다운로드 포트이다.
- **Port 161 / 162:** SNMP (Simple Network Management Protocol)
    - **161번 포트:** 네트워크 관리자(Manager)가 에이전트(Agent)의 상태를 조회하거나 설정할 때 에이전트 측에서 수신 대기하는 포트이다.
    - **162번 포트:** 에이전트 장비에 장애 등 예외 상황이 발생하여 관리자 시스템으로 알림을 보내는 **트랩(Trap) 신호 수신용 포트**이다.
- **Port 179:** BGP (Border Gateway Protocol) 자율 시스템(AS) 간 대규모 라우팅 정보 교환용 포트이며, TCP 기반으로 동작한다.
- **Port 443:** HTTPS (HTTP Secure) 암호화 보안 웹 서비스 기본 포트이다.
- **Port 514:** Syslog 시스템 로그 및 상태 진단 메시지를 원격 로그 서버로 전송할 때 사용하는 포트이며, UDP 기반으로 동작한다.

## 7. 기본 단위 접두사 및 회로 부품 판독법

### 7.1. 수치 접두사 단위 규격

- **양의 지수 (대량 데이터 및 주파수):** Kilo(10의 3승), Mega(10의 6승), Giga(10의 9승), Tera(10의 12승) 순으로 커진다.
- **음의 지수 (광통신 파장 및 소자 용량):** Milli(10의 -3승), Micro(10의 -6승), Nano(10의 -9승), Pico(10의 -12승) 순으로 작아진다.

### 7.2. 콘덴서(커패시터) 오차 부호 및 정전용량 정량 판독법

- **허용 오차 문자 코드 명세:** 전자회로 부품 표면 표기법에서 주로 사용하는 핵심 오차 기호이다.
    - **K 기호:** 정격 용량 대비 ±10%의 허용 오차 한계를 나타낸다.
    - **M 기호:** 정격 용량 대비 ±20%의 허용 오차 한계를 나타낸다.
- **정전용량(수치 기호) 판독 메커니즘:** 소자에 마킹된 연속된 세 자리 숫자를 기준으로 해석한다. 앞의 첫째와 둘째 자리는 용량의 유효숫자 상숫값이고, 세 번째 숫자는 10의 지수 승수(즉, 뒤에 붙는 0의 개수)를 의미하며, 최종 산출 단위는 피코패럿(pF)을 기본 기저로 삼는다.
    - **220 마킹:** 22 × 10의 0승 = 22 pF
    - **221 마킹:** 22 × 10의 1승 = 220 pF
    - **222 마킹:** 22 × 10의 2승 = 2,200 pF (단위를 한 단계 확장 변환하면 2.2 nF이 된다.)
    - **22M 종합 판독 예시:** 유효정전용량값은 22 pF이며, 해당 부품의 공정 허용 오차는 ±20%(M)인 커패시터 부품임을 뜻한다.

## 8. 기타 단답형 빈출 전산·통신 기출 용어

- **MTBF (Mean Time Between Failures, 평균 고장 간격):** 수리가 가능한 정보통신 시스템이나 장비가 가동된 후, **고장이 발생하여 수리된 시점부터 다음 고장이 발생할 때까지의 평균 운영 시간 간격**을 의미한다. 시스템의 신뢰성(Reliability)을 평가하는 주 지표이며 값이 클수록 우수하다.
- **MTTR (Mean Time To Repair, 평균 복구 시간):** 정보통신 장비에 장애나 고장이 발생한 시점부터, 정비 요원이 투입되어 수리를 완료하고 다시 정상 서비스 가동 상태로 **복구하기까지 소요되는 평균 정비 수리 시간**을 뜻한다. 시스템의 유지보수성(Maintainability)을 평가하는 지표이며 값이 작을수록 우수하다.
- **NRZ (Non-Return to Zero):** 디지털 신호를 선로 부호화(Line Coding)하여 전송할 때, 데이터 비트 하나의 주기(Pulse)가 지속되는 도중에 **전압 레벨이 중간의 0V 기준점으로 복귀(Return)하지 않고, 양(+) 또는 음(-)의 전압 전위를 끝까지 유지**하며 0과 1을 표현하는 변조 방식이다.
- **PDU (Protocol Data Unit, 프로토콜 데이터 단위):** 동일한 통신 계층 프로토콜 파트 간에 서로 규약을 맞추어 직접 주고받는 독립된 정보의 가상 기본 단위이다.
    - **2계층 (데이터 링크):** 프레임 (Frame)
    - **3계층 (네트워크):** 패킷 (Packet)
    - **4계층 (전송 계층):** 세그먼트 (Segment)
- **Polling & Selection (데이터 링크 제어 방식):** 주컴퓨터(Master)와 종속 단말기(Slave) 간의 점대다중 통신 회선 제어 메커니즘이다.
    - **Polling (폴링):** 주컴퓨터가 종속 단말기들에게 순차적으로 "현재 송신할 제어 데이터가 존재하는가?"를 물어보고 송신 권한을 부여하는 제어 방식이다. 단말에서 주컴퓨터 방향으로의 흐름을 유도한다.
    - **Selection (셀렉션):** 주컴퓨터가 특정 단말기를 지정하여 "지금 너에게 보낼 정보가 있으니 수신할 준비가 되었는가?"를 확인하고 데이터를 전송하는 방식이다. 주컴퓨터에서 단말 방향으로의 흐름을 제어한다.
- **QAM (Quadrature Amplitude Modulation, 직교 진폭 변조):** 주파수 한정 대역폭 내에서 고속 데이터 전송 효율을 극대화하기 위해, 하나의 반송파 신호 축을 기준으로 동위상 진폭 변조(ASK)와 직교위상 편이 변조(PSK)를 유기적으로 결합하여, **반송파의 진폭과 위상을 동시에 변화시키며 하나의 기호(Symbol)에 다수의 복합 비트 정보를 실어 전송**하는 고효율 디지털 변조 방식이다.
- **EMI / EMS (전자기 환경 적합성 EMC 기준)**
    - **EMI (Electromagnetic Interference, 전자기 간섭):** 전자 기기 내부의 고주파 회로 등에서 의도치 않게 발생하는 **유해 전자파 에너지가 외부 공간으로 방출되어, 인접한 타 전자 통신 장비의 정상적인 신호 처리에 장해를 유발**하는 현상이다. 방출 차단 기준을 통해 규제한다.
    - **EMS (Electromagnetic Susceptibility, 전자파 내성):** 외래 전자기 방사파 오염 환경 및 전력 서지 유입 속에서도, 해당 **전자 장비가 오작동이나 성능 저하를 일으키지 않고 원본 기능을 유지하며 버텨내는 내부 무선 내성(면역력)** 기술 능력이다.
- **채널 용량 (Channel Capacity):** 주어진 통신 채널 유선망 또는 무선 링크 환경 상에서, 물리적 오류를 발생시키지 않고 전송 가능한 이론적인 최대 정보 전송률(bps)을 의미한다.
    - **나이키스트 (Nyquist) 공식 (잡음이 없는 이상적 채널):** B는 채널 대역폭, M은 부호의 신호 레벨 진수이다. $$C = 2B \log_2 M$$
    - **샤논 (Shannon) 공식 (백색 가우시안 잡음이 존재하는 실제 채널):** B는 대역폭, S/N은 신호 대 잡음 전력비이다. $$C = B \log_2 \left(1 + \frac{S}{N}\right)$$
- **캡슐화 (Encapsulation):** 송신측 정보 처리 과정에서, 상위 계층으로부터 전달받은 실제 데이터 페이로드(Payload) 전·후면에 **해당 통신 계층의 규격 제어 정보(주소, 오류 제어 코드 등)를 담은 헤더(Header)와 트레일러(Trailer)를 물리적으로 결합**하여 하위 계층으로 전달하는 프로토콜 데이터 형성 과정이다.
- **고스트 (Ghost) 현상:** 송·수신 안테나 간 전송 선로 상의 임피던스 정합(Matching) 불량 또는 지형지물에 의한 다중 경로 반사파 변형으로 인해, TV 수상기 화면 상에 **원래의 비디오 화상 옆에 그림자 모양의 이중·삼중 화상이 겹쳐서 비쳐 보이는 영상 왜곡 열화 현상**이다.
- **멀티모달 인터페이스 (Multimodal Interface):** 전통적인 키보드, 마우스 입력 구조를 넘어 **인간의 음성 신호, 신체 제스처 인식, 시선의 움직임, 생체 인식 등 다양한 감각 기관의 물리 입력 채널들을 결합**하여 시스템과 고도화된 상호작용을 수행하는 사용자 인터페이스 기술이다.
- **햅틱 (Haptics):** 가상 물리 현실 시스템이나 모바일 터치 스크린 화면 조작 시, 사용자에게 미세 진동, 물리적인 힘(Force Feedback), 기계적 회전 질감을 피부로 역피드백하여 **실제 물리적 물체를 만지는 듯한 인위적인 촉각적 실재감을 인지하게 하는 기술**이다.
- **POTS (Plain Old Telephone Service):** 가장 전통적인 구리선(트위스트 페어) 인프라 기반의 **공공 교환 전화망(PSTN) 체계를 통해 순수 음성 통신 기능만을 아날로그 방식으로 제공**해 온 일반 기본 전화 서비스의 기술적 통칭이다.
- **TRS (Trunked Radio System, 주파수 공용 통신):** 다수의 무선 통신 가입자들이 한정된 소수의 주파수 채널 그룹을 고정 점유하지 않고, 시스템 제어국 관리를 통해 **통화 요청이 발생할 때마다 비어 있는 주파수 채널을 동적으로 자동 할당받아 공동 공유 사용하는 고효율 무선 이동 자원 할당 시스템**이다. 경찰, 소방, 재난망의 모태 기술이 된다.
