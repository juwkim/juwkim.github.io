[정보처리기사 실기] SQL 실기 문법

2026년 10월 24일6분 읽기

실기에서 SQL은 매회 빠지지 않고 출제됩니다. 이 글에서는 시험에 자주 나오는 문법을 DDL·DML·DCL 순서로 정리합니다. (시안용 예시 본문입니다.)

1. 조회와 그룹화

그룹 함수를 쓸 때 조건은 WHERE가 아니라 HAVING에 둡니다. 실행 순서를 기억하면 헷갈리지 않습니다.

SELECT  dept, COUNT(*) AS cnt
FROM    employee
WHERE   salary >= 3000
GROUP BY dept
HAVING  COUNT(*) > 2
ORDER BY cnt DESC;  -- FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY

실행 순서와 작성 순서가 다르다는 점이 단골 함정입니다.

2. 명령어 분류

분류명령어설명
DDLCREATE ALTER DROP구조 정의
DMLSELECT INSERT UPDATE데이터 조작
DCLGRANT REVOKE권한 제어
  • DDL은 자동 커밋됩니다.
  • DELETE는 롤백할 수 있지만 TRUNCATE는 불가합니다.
