# 글 다듬기 결과 — 고친 사실과 확인이 필요한 곳 (2026-11-21)

105편을 `docs/editing-guide.md` 기준으로 다듬은 결과 중, 주원님이 알아야 하거나 판단해야 할 것만 모았습니다. 확인이 끝난 항목은 지워 주세요.

## 바로잡은 사실·기술 오류

| 글 | 바꾸기 전 → 후 | 이유 |
|---|---|---|
| 장인에서 모험가로 | 세니타이저로 메모리 오버플로우를 정적으로 → 새니타이저로 메모리 오류를 실행 중에 | 새니타이저는 실행 중에 오류를 잡는 도구 |
| SCPC 본선 후기 | 캡션 "2025 / 2026 기념 키보드" → 사진별 캡션 2개 | 두 사진의 내용이 달랐음 |
| 빅데이터분석기사 실기 후기 | 코드 `full[:len(x)]` → `full[:len(train)]` | `x`가 정의되지 않아 실행 시 오류 |
| ADsP 후기 | 시험일 2025.08.08 → 2026.08.08 | 접수·결과 화면 날짜와 맞춤 |
| AICE Associate 후기 | 국가공인자격 → 국가공인 민간자격 | 교재 표지 표기 |
| 정보통신기사 PART 0 | CDM → CDMA, WPAN 설명, nslookup "역조회" → "조회", POTS 케이블 종류, IPsec 터널 모드 헤더, OFDMA 설명 | 용어와 정의 오류 6건 |
| 정보통신기사 Shannon | 깨진 문장 1곳, 수식 표기 | 문장 복구 |

| 실습 06 풀이 | 평균이 줄어드는 원인 설명 | 원인은 분모 |
| 공부노트 06 | `repair_frequency` → `repair_freq` | 실제 열 이름 |
| 책을 빌려서 공부하는 방법 | 『반려공구』 모호 저 / 라이프앤페이 → 모호연 저 / 라이프앤페이지 | 표지 사진의 표기 |
| 지게차 필기 후기 | 제목 "`26년" → "'26년" | 백틱 오타 |
| 정주영 창업경진대회 | 11개 → 14개 창업팀, 몬죠 → Mongeo(몬죠), "붕괴 30분 전" → "붕괴 전", "정유사 15년" → "석유화학 업계 15년", 시간 서술을 "본 행사 14시 시작, 17시 30분쯤 퇴장"으로 | 주원님 확인, 발표 화면·본문과 맞춤 |
| 건강한 몸과 운동 능력 | 군대 식단 하루 4,000kcal → 3,000kcal 정도 | 주원님 확인 |
| 좋은 개발자에 대한 고찰 | `synchronized`는 잠금과 happens-before 둘 다, numpy·pandas 엔진 C·Rust → C·Cython | 기술 사실 |
| 컴활 1급 필기 후기 | 도전 글 3월 3일 → 3월 2일 | 준비 글 날짜 |
| 정보처리기사 필기 후기 | 3과목 "암기 없이도 고득점" → "큰 암기 부담 없이 안정적으로 점수 확보" | 실제 점수 70점 |
| CSTS 후기 | "미룬 이유가 다른 데 있었던 것은 아닙니다" → "미룬 데에는 이유가 있었습니다" | 뒤 문단과 연결 |
| AI라는 흐름 위에서 노를 젓는 법 | 호크아이: 선수 요청 시 재판독, 지금은 많은 대회가 전자 라인 판정 | 사실 정확성 |
| 글을 잘 쓰고 싶다 | 뫼르소: 울지 않았다는 사실이 재판에서 단죄의 근거가 됨 | 해석임을 분명히 |
| 책을 빌려서 공부하는 방법 | 『데이터 분석 전문가 가이드』 발행처 한국데이터산업진흥원 → 한국데이터진흥원, 제목 띄어쓰기 | 표지 표기 |
| 유형별 실습 16편 | 내용 없는 공통 캡션 6개, 문제편 "핵심 요약" 상자 8개, "행의 기준" 열 삭제 | 상투 문구 |

## 확인이 필요한 곳 (고치지 않음)

### 내용이 서로 맞지 않는 곳
- **책을 빌려서 공부하는 방법**: 신트리도서관에서 빌린 책인데 표지에는 "인천북구도서관" 라벨이 붙어 있습니다. 어느 쪽이 맞는지 사진만으로는 알 수 없어 본문을 그대로 두었습니다.

### 사실 확인이 필요한 서술
- **AI라는 흐름 위에서 노를 젓는 법**: 서울대 사례는 출처를 확인하지 못해 그대로 두었습니다.

### 시험 기준이라 그대로 둔 것
- **SQL 실기 문법**: UNION 자동 정렬, UNIQUE와 NULL, ALTER VIEW (요청대로 유지)
- **정보통신기사**: 3R 용어 짝, TLS·ARP 계층 분류
- **한국사**: 『고려사절요』의 왕(문종/단종), 자유시 참변의 "소련"
