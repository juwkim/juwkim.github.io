# 글 다듬기 결과 — 고친 사실과 확인이 필요한 곳 (2026-11-21)

105편을 `docs/editing-guide.md` 기준으로 다듬은 결과 중, 주원님이 알아야 하거나 판단해야 할 것만 모았습니다. 확인이 끝난 항목은 지워 주세요.

## 확인이 필요한 곳 (고치지 않음)

### 내용이 서로 맞지 않는 곳
- **정주영 창업경진대회**: "11개 창업팀"이라고 했지만 소개된 팀은 14개입니다. 몬죠는 "28분 먼저 감지"와 "붕괴 30분 전 경고"가 서로 다르고, 발표 화면의 팀명은 "Mongeo"입니다. 본문은 14시~17시 30분, 타임테이블은 13:00~18:00입니다.
- **컴활 1급 필기 후기**: "3월 3일에 도전 글을 올렸다"고 했지만 준비 글의 날짜는 3월 2일입니다.
- **정보처리기사 필기 후기**: 3과목을 "별도의 암기 없이도 고득점"이라고 했지만 점수는 70점입니다.
- **CSTS 후기**: "공부를 미룬 이유가 다른 데 있었던 것은 아닙니다."가 바로 뒤의 설명과 맞지 않습니다.
- **책을 빌려서 공부하는 방법**: 신트리도서관에서 빌린 책인데 사진에는 "인천북구도서관" 라벨이 붙어 있습니다.

### 사실 확인이 필요한 서술
- **좋은 개발자에 대한 고찰**: "`synchronized`의 진짜 역할은 잠금이 아니라 happens-before"라고 했지만, 실제로는 둘 다입니다. numpy와 pandas는 주로 C와 Cython으로 만들어졌습니다.
- **AI라는 흐름 위에서 노를 젓는 법**: 테니스 호크아이는 오랫동안 보조 판독이었습니다. 서울대 사례는 출처를 확인해야 합니다.
- **글을 잘 쓰고 싶다**: 뫼르소의 사형 선고 이유는 해석에 가깝습니다(재판의 죄목은 살인).
- **건강한 몸과 운동 능력**: "군대 식단 하루 4,000kcal"는 일반적으로 알려진 수치(3,000kcal대)와 다릅니다.

### 시험 기준이라 그대로 둔 것
- **SQL 실기 문법**: UNION 자동 정렬, UNIQUE와 NULL, ALTER VIEW (요청대로 유지)
- **정보통신기사**: 3R 용어 짝, TLS·ARP 계층 분류
- **한국사**: 『고려사절요』의 왕(문종/단종), 자유시 참변의 "소련"

### 원문에 있던 상투 문구
- **유형별 실습 시리즈**: 일부 캡션과 "핵심 요약" 상자에 내용 없는 공통 문구가 있습니다(예: "…의 실행 결과를 보여 줍니다. 단위와 관측 대상을 본문의 기준으로 읽습니다."). 지우거나 실제 내용으로 바꿀지 결정이 필요합니다.
