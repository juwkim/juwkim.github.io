## 확정된 결정

### 기술
- **Astro**로 새로 구축 (Jekyll/al-folio는 폐기, 이전 코드는 git 기록에 남음)
- 배포: `master` push → GitHub Actions → GitHub Pages / PR은 빌드 검사만
- 레포를 **공개**로 전환 (2026-11-21) — 무료 계정은 비공개 레포로 Pages 불가였던 것이 사이트가 안 열린 원인. 전환 전 git 기록에서 비밀 정보 없음 확인
- 브랜치: `master` 하나만 사용 (`gh-pages` 삭제함). 큰 작업만 임시 브랜치 → PR → merge 후 삭제
- al-folio 파일은 전부 삭제 (2026-11-21, 사용자 승인)
- 개발 환경: Node.js v26 LTS를 사용자 폴더(`%LOCALAPPDATA%\Programs\nodejs`)에 설치, 사용자 PATH에 추가
- 검색: Pagefind (서버 없는 정적 검색) / 다크 모드: 시스템 설정 따름 + 수동 전환
- RSS: 화면에 링크는 없이, 파일만 자동 생성 (검색엔진/네이버 서치어드바이저용)

## 초기 설정 체크리스트

### 블로그

- [ ] Node.js 26 설치 후 `node -v`로 26.x인지 확인
- [ ] 저장소 루트에서 `npm ci`로 의존성 설치 (lockfile 기준)
- [ ] `npm run dev`로 로컬 개발 서버 실행 후 페이지 확인
- [ ] `npm run build`로 프로덕션 빌드가 오류 없이 끝나는지 확인
- [ ] Codex Cloud에서는 게시된 환경의 설치·시작 지침을 따르고, 필요할 때만 의존성을 다시 설치

### Google Drive

- [ ] 현재 상태 확인: Cloud 환경에는 Drive 커넥터가 없고, `rclone`은 설치되어 있지만 remote와 설정 파일이 없음
- [ ] 기존 Drive 연결 기록은 이전 환경 기준이므로 재사용하지 않음
- [ ] 사용자가 직접 `rclone config`에서 Google Drive remote를 만들고 OAuth 로그인 및 권한 승인 진행 (읽기 전용 scope 권장)
- [ ] OAuth 클라이언트 ID/시크릿, 토큰, `rclone.conf` 등 인증 값은 저장소에 커밋하지 않음 (저장소 밖에 보관, 필요 시 `.gitignore` 확인)
- [ ] 연결 후 읽기 전용으로 검증: `rclone lsd <remote>:` / `rclone lsf <remote>:<폴더>`로 목록만 조회하고 쓰기·삭제 명령은 실행하지 않음
- [ ] 사용자가 공개를 승인한 파일만 사이트로 복사하고, 승인 내역을 기록
